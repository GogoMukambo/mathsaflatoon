1 Generating Sequences (1)

Each number in a sequence is called a term. The rule that gets you from one term to the next is the term-to-term rule. If it has '...', it's an infinite sequence.

Solved Example: Term-to-term rules

The first term of a sequence is 5. The rule is: Multiply by 2 and then add 1. Write the first three terms.

  • First term = 5
  • Second term = 5 × 2 + 1 = 11
  • Third term = 11 × 2 + 1 = 23

Answer: 5, 11, 23

2 Generating Sequences (2)

You can find term-to-term rules for sequences drawn as patterns by counting the shapes in each stage.

Solved Example: Patterns of Matchsticks

A sequence of triangle patterns is made of matchsticks: 3, 6, 9...

  • Pattern 1 = 3 matchsticks.
  • Pattern 2 = 6 matchsticks.
  • Pattern 3 = 9 matchsticks.
  • Term-to-term rule: Add 3.

Answer: Pattern 4 will have 12 matchsticks.

3 Using the nth Term

If you let n represent the position number of an unknown term, you can use algebra to write the rule as the nth term.

Solved Example: nth term rule

Sequence: 12, 24, 36, 48, 60, ...

  • The sequence is the 12 times table.
  • Position 1: 1 × 12 = 12
  • Position 2: 2 × 12 = 24
  • The rule is: Term = position number × 12.

Answer: nth term = 12n

4 Representing Simple Functions

A function is a relationship between two sets of numbers. A function machine maps an input to an output. To work backward, use an inverse operation.

Solved Example: Inverse Function Machine

Machine: input -> [ × 2 ] -> output (10)

  • The output is 10.
  • To find the input, use the inverse operation of multiplication.
  • The inverse of "× 2" is "÷ 2".
  • 10 ÷ 2 = 5.

Answer: Input is 5
